# Автозаполнение внешних источников

Скрипт: [fill_spaceapps_other_data.js](../scripts/fill_spaceapps_other_data.js).
Он содержит все 24 пары названий и публичных URL из текущей заявки Arescope.
В присланном снапшоте нужный раздел связан с полем `projectReferences`; лимит
компонента — 25 ссылок. Скрипт использует обычные события полей и кнопку
**Add New Link**, проверяя также значение, которое сохраняет React-форма.

1. Открой настоящую страницу **редактирования** проекта в Chrome.
2. Раскрой **Project Information → Space Agency Partner & Other Data**.
3. Открой JS-файл как текст и скопируй весь код.
4. Нажми **F12 → Console**, вставь код и нажми **Enter**.
5. Дождись сообщения **Arescope sources ready**. Проверь список и сохрани
   изменения штатной кнопкой формы самостоятельно.

Не запускай скрипт в сохранённом HTML-снапшоте: у него может отсутствовать
работающее состояние формы. Если форма поменяла структуру, скрипт остановится
с сообщением в Console.

Повторный запуск пропускает источники с уже указанным URL. Непустые строки,
включая частично заполненные, сохраняются. Если вместе с ними все 24 источника
не помещаются в лимит 25 строк, импорт остановится до начала изменений.
Скрипт не нажимает Save/Submit, не меняет NASA Data, не использует токены и
не делает собственных сетевых запросов. Сайт может обрабатывать изменения
так же, как при ручном заполнении; последующее сохранение проверяется на сайте.

Функциональность проверена на изолированной React-форме, воспроизводящей
логику компонента из снапшота. Это проверка заполнения состояния формы,
а не подтверждение сохранения на сервере Space Apps.
