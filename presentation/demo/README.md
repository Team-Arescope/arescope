# Thirty-second fleet demonstration

`Arescope-Fleet-Demo-30s.mp4` is a silent 1920 × 1080 H.264 video, exactly
30 seconds / 900 frames, with Russian captions. It shows surveying, a simulated
wheel obstruction, autonomous assistance, Guardian validation and resumed work.

The recording replays states produced by the deployed FleetSimManager and
GuardianEngine on archived HiRISE terrain. Initial adjacent survey lanes were
staged for a short demonstration; mission time is accelerated. This is a
synthetic service scenario, not a hardware repair recording. Production mission
state was not changed. The PNG is a preview frame.

The reusable cloud encoding CLI is `scripts/export_fleet_demo.py`.
